# Host tools

- `romverify/` — exact LeafGreen USA Rev 1 identity verification.
- `assets/` — versioned manifest validation and SHA-1-gated local extraction.
- `gfxconv/` — indexed GBA graphics primitives and PS1 TIM prototype.

These tools are intentionally usable without the PS1 compiler so conversion/validation logic can be tested in normal CI. Commercial inputs/outputs remain local and ignored.
